# Plugin Watch Scope Rules

1. **Specific Plugin Focus**: Watch only the specific plugin if the user request is limited to a specific plugin.
2. **Cross-Plugin Dependencies**: Watch only cross-plugin files and configurations if the user request involves cross-plugin dependencies.
3. **Strict Folder Limitation**: ONLY look within the `plugins` folder. DO NOT go outside of `plugins` files for research or analysis unless explicitly directed otherwise for specific cross-plugin dependencies.
